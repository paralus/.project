# Security Policy

## Reporting Security Issues

The Paralus maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/paralus/paralus/security/advisories/new) form.

For more details, see the [Paralus security policy](https://github.com/paralus/paralus/blob/main/SECURITY.md).
